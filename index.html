Laboratorio Interactivo de Álgebra Lineal

Una colección de herramientas interactivas para visualizar conceptos fundamentales del álgebra lineal, desde transformaciones en 2D y 3D hasta cambios de base.

Transformaciones 2D

Visualice cómo una matriz 2x2 transforma el espacio. Explore el determinante, los vectores propios y el kernel de forma interactiva.

Abrir aplicativo →

Cambio de Base

Manipule los vectores de una nueva base y observe cómo cambian las coordenadas de un vector arbitrario entre la base estándar y la nueva.

Abrir aplicativo →

Composición de Transformaciones

Aplique dos transformaciones secuencialmente y visualice el resultado. Compruebe que el orden de la multiplicación de matrices importa.

Abrir aplicativo →

Transformaciones 3D

Una potente herramienta para visualizar transformaciones en tres dimensiones. Analice proyecciones, rotaciones, reflexiones y más.

Abrir aplicativo →

Matrices no Cuadradas

Explore cómo las matrices no cuadradas mapean vectores entre espacios de diferentes dimensiones (ej. de ℝ² a ℝ³).

Abrir aplicativo →

Transformaciones no Lineales

Una vez entendidas las transformaciones lineales, vale la pena comprender cómo se ven algunas que no siguen estas reglas.
