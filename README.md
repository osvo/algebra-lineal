# Laboratorio Interactivo de Álgebra Lineal

Este es un proyecto web diseñado para proporcionar una forma interactiva y visual de aprender conceptos fundamentales del álgebra lineal. A través de una serie de aplicaciones, los usuarios pueden manipular parámetros y observar en tiempo real los efectos sobre vectores y espacios vectoriales.

## Descripción

El proyecto consiste en una colección de herramientas interactivas que ayudan a visualizar conceptos clave del álgebra lineal. Es ideal para estudiantes, educadores o cualquier persona interesada en desarrollar una intuición más profunda sobre temas como transformaciones, cambios de base y más.

## Aplicaciones Interactivas

El laboratorio incluye las siguientes aplicaciones:

- **Transformaciones 2D:** Visualice cómo una matriz 2x2 transforma el espacio. Explore el determinante, los vectores propios y el kernel de forma interactiva.
- **Cambio de Base:** Manipule los vectores de una nueva base y observe cómo cambian las coordenadas de un vector arbitrario entre la base estándar y la nueva.
- **Composición de Transformaciones:** Aplique dos transformaciones secuencialmente y visualice el resultado. Compruebe que el orden de la multiplicación de matrices importa.
- **Transformaciones 3D:** Para visualizar transformaciones en tres dimensiones. Analice proyecciones, rotaciones, reflexiones y más.
- **Matrices no Cuadradas:** Explore cómo las matrices no cuadradas mapean vectores entre espacios de diferentes dimensiones (por ejemplo, de ℝ² a ℝ³).
- **Transformaciones no Lineales:** Una vez entendidas las transformaciones lineales, vale la pena comprender cómo se ven algunas que no siguen estas reglas.
